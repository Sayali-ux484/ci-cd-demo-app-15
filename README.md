# 🚀 CI/CD Pipeline Demo Website

This project demonstrates a simple website deployed using AWS CI/CD pipeline.

## Tech Used:
- HTML
- CSS
- JavaScript
- AWS S3
- AWS CodePipeline
- AWS Lambda

## Features:
- Auto deployment from GitHub
- Simple responsive UI
- Cloud hosting using AWS

## How it works:
GitHub push → CodePipeline → Lambda → S3 Deployment
